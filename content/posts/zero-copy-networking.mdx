## Copies cost memory bandwidth

Sending a file through user space can copy data between kernel and application buffers more than once. At high throughput, those copies compete with useful application work.

## Pick the right primitive

`sendfile` is a strong fit for file-to-socket transfers. `splice` can connect file descriptors through a kernel pipe. Both reduce copies, but neither removes the need for flow control and error handling.
